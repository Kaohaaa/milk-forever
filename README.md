# 🥛 Milk Forever
> _Time fades, **Wild Dog Milk** remains._

## 📌 Description
This is just Koolhaas's first attempt at making a Fabric mod, so it's quite **rudimentary**.

## ✨ Additions

### Advancement

- **Milk Forever**
    - Can be required by obtaining a Wild Dog Milk.

### Items

- **Carton**
    - Can be crafted using 8 Paper.

- **Wild Dog Milk**
    - Can be obtained from wolves by pressing `use` while looking at them with a Carton.
    - Inflicts Nausea effect after eating.

## 📥 Download
You can get the mod from [Modrinth](https://modrinth.com/mod/milk-forever/versions) or the project's [Release](https://github.com/Kaohaaa/milk-forever/releases) page.
